WALLPAPER PICKER / 現在の実装

状態と操作をまとめたオブジェクト構成図

各オブジェクトは Luau のテーブルと setmetatable で実装しています。言語組み込みのクラスではありません。実線は保持する参照、破線はプラグインの状態チャネルを介した通信を示します。

メタテーブルによるオブジェクト指向パターン

オブジェクトと関係

− 保持する状態　＋ 呼び出す操作。アクセス制御はありません。

«表示»PickerPanel

  • − coordinator: PickerCoordinator
  • ＋ render()
  • ＋ open() / close()

«調停»PickerCoordinator

  • − session: PickerSession
  • − browser: MediaBrowser
  • − thumbnails: ThumbnailCache
  • − favorites: FavoriteStore
  • − palettes: PaletteManager
  • − wallpapers: WallpaperController
  • ＋ dispatch(action, value?, extra?)
  • ＋ snapshot(): PickerView
  • ＋ favorite(kind, path)

«画面状態»PickerSession

  • − tab: MediaKind
  • − monitorIndex: number
  • − showPalette: boolean
  • ＋ selectTab(kind)
  • ＋ selectMonitor(index)
  • ＋ togglePalette()
  • ＋ connector()

«一覧・検索»MediaBrowser

  • − entries: MediaEntry[]
  • − query: string
  • − sortMode: SortMode
  • − folder: string?
  • − thumbnails: ThumbnailCache
  • ＋ scanImages() / scanVideos()
  • ＋ setQuery(query)
  • ＋ cycleSort()
  • ＋ enterFolder(path) / goUp()
  • ＋ visibleImages() / visibleVideos()

«画像の準備»ThumbnailCache

  • − ready: Map<Path, Path>
  • − pending: Set<Path>
  • − queue: Job[]
  • ＋ get(path)
  • ＋ request(path, kind)
  • − pump()

«永続化»FavoriteStore

  • − images: FavoriteMap
  • − videos: FavoriteMap
  • ＋ load()
  • ＋ get(kind, path)
  • ＋ toggle(kind, path, source, scheme)

«配色»PaletteManager

  • − groups: PaletteGroup[]
  • − currentSource: string?
  • − currentScheme: string?
  • ＋ getGroups()
  • ＋ selectSource(source)
  • ＋ apply(source, scheme)
  • ＋ toggleMode()

«壁紙の適用»WallpaperController

  • − session: PickerSession
  • − palettes: PaletteManager
  • − favorites: FavoriteStore
  • − selectedKind: string
  • − selectedPath: string
  • ＋ applyImage(path) / applyVideo(path)
  • ＋ toggleFavorite()
  • ＋ pauseOrResume()
  • ＋ stop()

«独立サービス»service.luau

  • − processes: ProcessMap
  • − assignments: VideoMap
  • ＋ start(output, path)
  • ＋ freeze(output) / thaw(output)
  • ＋ clear(output)
状態チャネルで通信
保持する参照・メソッド呼び出し状態チャネル経由の通信各オブジェクトは、このパネルの実行単位で原則１つです。

データと操作を同じ場所へ置く

検索語と並べ替えは MediaBrowser が保持し、検索・整列・一覧生成も同じオブジェクトが担当します。サムネイルの待ち行列は ThumbnailCache が保持します。

依存の向きを固定する

PickerPanel は実行時に PickerCoordinator を参照します。調停役が各オブジェクトを呼び出し、下位のオブジェクトから画面を参照しません。

既存サービスの境界を保つ

WallpaperController が動画の操作を依頼し、service.luau が mpvpaper のプロセスを管理します。サービスは現在も手続き的なモジュールです。
